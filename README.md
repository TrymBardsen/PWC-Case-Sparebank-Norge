# PWC-Case-Sparebank-Norge

Om Sparebanken Norge
En av Norges største sparebanker, med finansielle tjenester til privatpersoner og bedrifter over hele landet. Sterke lokale relasjoner, høy tillit og et landsdekkende rådgivernettverk gir nærhet til kundene.
Oppgaven: Fremtidsbile 2027
Alle har tilgang til AI, og mange bedriftskunder har egne AI-verktøy. Sparebanken Norge vil fortsatt ha ekte mennesker i kundefront som konkurransefortrinn. Utvikle en løsning som gjør rådgiveren til en AI-forsterket superhelt og gir kunden mer verdi enn generelle AI-verktøy alene. Tenk radikalt om fremtidens rådgivning. Vis hva som kan prøves ut i 2027, og hvilke antakelser om teknologi, data og kundeadferd det langsiktige konseptet bygger på.
 
Bakgrunn og kontekst
Kundene forventer raskere svar, proaktiv rådgivning, bedre innsikt, personlige anbefalinger og sømløse digitale opplevelser. Banken kan kombinere data, kompetanse og markedsinnsikt med AI. Hva er rådgiverens unike verdi i denne verdenen?
Mulighetsrom og viktige spørsmål
Velg én konkret kundesituasjon: likviditetsskvis, oppkjøp/fusjon eller grønn omstilling. Dere kan også foreslå en annen situasjon med et tydelig kundebehov. Vis hvilken beslutning kunden trenger hjelp til, hva kundens egen AI kan løse, og hva banken og rådgiveren tilfører. Løsningen kan være en tjeneste, arbeidsmåte, AI-agent eller forretningsmodell.
 
Tilgjengelig materiale og gjennomføring
Derefinnerrelevantbakgrunnsmateriale, som årsrapport, offentlig informasjon, strategiske føringer og informasjon offentlig.Bruk gjerne AI-verktøy gjennom hele hackathonet. Presenter underveis og bruk tilbakemeldinger fra fagpersoner og mentorer til å videreutvikle konseptet.
